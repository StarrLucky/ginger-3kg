# Синк еды в Apple Health через «Команды» (iOS Shortcuts)

У Apple Health нет облачного API — записывать в него можно только с iPhone.
Мостик — приложение «Команды»: шорткат забирает из бэкенда невыгруженные записи,
пишет их в Health и подтверждает выгрузку. Дубликатов не будет: бэкенд отдаёт
каждую запись ровно один раз (очередь `/export/pending` → `/export/ack`).

## Эндпоинты (в Custom GPT их нет — только для шортката)

- `GET /export/pending` → `{count, ack_token, items: [{name, consumed_at, consumed_at_local, calories_kcal, protein_g, fat_total_g, carbs_g, ...}]}`
  - в поле Date шортката подставляй **consumed_at_local** (`2026-07-05 23:48:50`, локальное время) —
    ISO-строку `consumed_at` с микросекундами и `+00:00` iOS парсит криво (теряет время, ставит полдень)
- `POST /export/ack?token=<ack_token>` → помечает отданные записи выгруженными

База: `https://unstony-brain-burlily.ngrok-free.dev/food`
Заголовки для обоих запросов: `X-API-Key: <ключ из ~/food_api/.env>` и `ngrok-skip-browser-warning: true`.

## Шорткат «Еда → Health»

1. **Получить содержимое URL** (Get Contents of URL)
   - URL: `https://unstony-brain-burlily.ngrok-free.dev/food/export/pending`
   - Метод GET, заголовки — оба из списка выше.
2. **Получить значение словаря** (Get Dictionary Value): `items` из результата шага 1.
3. **Повторять с каждым** (Repeat with Each) по `items`, внутри повтора:
   - Получить значение словаря `calories_kcal` из «Элемент повтора»;
   - **Записать пробу здоровья** (Log Health Sample): тип **Пищевая энергия / Dietary Energy**,
     величина = `calories_kcal`, ккал, дата = значение `consumed_at_local` из «Элемент повтора».
     ВАЖНО: у токена-переменной в поле Value открой настройки и поставь Type = **Number**
     (по умолчанию iOS ставит «Health sample» и пишет 0), у токена в Date — Type = **Date**;
   - (по желанию) ещё три «Записать пробу здоровья»: **Белки** = `protein_g`,
     **Жиры (всего)** = `fat_total_g`, **Углеводы** = `carbs_g`, та же дата.
4. После цикла: Получить значение словаря `ack_token` из результата шага 1.
5. **Получить содержимое URL**:
   - URL: `https://unstony-brain-burlily.ngrok-free.dev/food/export/ack?token=[ack_token]`
     (вставь переменную ack_token прямо в URL — кодировать не нужно, сервер понимает),
   - метод POST, те же заголовки.
6. (по желанию) **Показать уведомление**: «Синк: [count] позиций».

При первом запуске iOS спросит разрешение на запись в Здоровье — разреши
Энергию/Белки/Жиры/Углеводы.

## Автозапуск

«Ежечасно» и «мгновенно» iOS не умеет. Рабочие варианты:

- **Автоматизация по времени**: Команды → Автоматизация → «Время дня» →
  «Выполнять сразу» (без подтверждения). Сделай 3–4 штуки: 13:00, 18:00, 23:00.
- Плюс запуск руками: виджет на экране, кнопка действия (Action Button) или «Привет, Siri, еда в Health».
- Хочется по-настоящему мгновенно — приложение Pushcut (бэкенд дёргает их webhook →
  пуш на iPhone запускает шорткат), но для фонового запуска без тапа нужен их
  платный Automation Server. На старте проще жить с расписанием.

## Ограничения

- Первый запуск выгрузит **всю** историю записей (всё, что накопилось с момента деплоя).
- Если удалить запись в GPT **после** того, как она уже ушла в Health, — из Health она
  сама не исчезнет, удали вручную в приложении Здоровье. Не выгруженные удаляются чисто.
- MyFitnessPal: публичного API нет (закрыт с 2018), интеграция невозможна.
  Garmin получает «потреблённые калории» только из MyFitnessPal — тоже тупик.
  Apple Health — центральная точка: из него данные читают многие приложения.
